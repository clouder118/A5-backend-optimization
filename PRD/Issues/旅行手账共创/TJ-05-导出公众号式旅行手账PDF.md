# TJ-05 导出公众号式旅行手账 PDF

- 类型：AFK
- 状态：`completed`
- 用户故事：63–67

## Parent

[旅行手账共创 PRD](../../旅行手账共创-PRD.md)

## What to build

为游客自己的草稿和已发布手账提供真正可下载的 PDF。后端使用 ReportLab 生成纵向多页中文图文文件，使用已经处理过的展示图片，保持总标题、昵称、创作日期、开场、各图片段落和结尾的阅读顺序。页尾仅保留低调产品名称。

导出只读取当前已保存的手账快照，不改变草稿、发布状态或社区内容。文件不包含账号 ID、EXIF、定位、点赞数和管理状态；失败时返回可理解错误且允许重试。

## Acceptance criteria

- [x] 游客可以从编辑页和“我的手账”下载自己手账的 PDF。
- [x] 未登录游客和非作者无法导出手账。
- [x] PDF 使用纵向多页布局并正确显示中文、标题、昵称、日期、正文和图片。
- [x] 每张图片与对应段落保持正确顺序，不被重复或遗漏。
- [x] 页尾只显示低调产品名称。
- [x] 文件名使用安全处理后的标题和日期，不包含用户原始文件名或路径。
- [x] PDF 不包含账号 ID、EXIF、定位、点赞数和社区状态。
- [x] 导出失败不改变手账或社区数据，并提供可重试响应。
- [x] ReportLab 和 Pillow 依赖只用于旅行手账相关能力。
- [x] 后端测试验证权限、响应类型、下载文件名、PDF 文件头、文字和图片基本完整性。
- [x] 前端流程测试验证下载入口和浏览器实际收到 PDF 文件。
