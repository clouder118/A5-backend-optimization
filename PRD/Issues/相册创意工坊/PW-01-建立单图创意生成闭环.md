# PW-01 建立单图创意生成闭环

- 类型：AFK
- 状态：`completed`
- 用户故事：1–18、47、51、60–62、75–80、85–87
- 演示入口：游客端 `/photo-workshop`
- 负责人方向：前端体验、后端工程

## Parent

[相册创意工坊 PRD](../../相册创意工坊-PRD.md)

## What to build

交付第一条完整的单图创意生成链路。游客可以从“旅行手账共创”下方进入“相册创意工坊”，上传一张 JPEG、PNG 或 WebP 图片，填写创意提示词，并使用默认的智能比例、1K、1 张参数发起生成。

前端所有远程访问通过统一 API 层；后端使用独立的 Seedream 配置和服务边界调用 `doubao-seedream-5-0-pro-260628`，禁止把 Key 或供应商请求放入浏览器。成功结果在 1:1 区域内完整适配展示，非正方形图片不裁剪、不拉伸。游客可以点击结果打开只包含关闭/返回和右上角下载的大图预览。

本切片建立可替换的供应商传输边界，自动测试使用假传输验证成功与失败，不读取或消费真实 Key。未配置真实 Key 时，后端返回友好的配置错误，不影响服务启动和其他游客端功能。

## Acceptance criteria

- [x] 游客端导航新增“相册创意工坊”，位置紧接在“旅行手账共创”下方。
- [x] `/photo-workshop` 沿用当前游客端访问规则，不新增认证或权限机制。
- [x] 页面初始创作区在 PC 端居中展示，并保持现有游客端视觉语言。
- [x] 上传入口只接受一张 JPEG、PNG 或 WebP，选择第二张时进入替换流程。
- [x] 创意提示词非空且不超过 2000 个字符，并显示实时字符数。
- [x] 生成前同时校验参考图和提示词；缺少任一项时不调用后端。
- [x] 默认参数为智能比例、1K、1 张。
- [x] 前端通过统一 API 客户端提交生成请求，不直接访问模型供应商。
- [x] 后端使用独立环境配置调用指定 Seedream 模型，真实 Key 不进入前端或版本库。
- [x] 模型成功结果以浏览器可预览和下载的形式返回。
- [x] 页面内结果框始终为 1:1，非正方形图片完整适配且不裁剪、不拉伸。
- [x] 点击结果图打开大图预览，预览只提供关闭/返回和右上角下载。
- [x] 下载保留返回格式和清晰度，文件名符合“灵诗音-相册创意-日期时间”规则。
- [x] 未配置或调用失败时显示脱敏的友好错误，不出现堆栈、Key 或供应商原始响应。
- [x] 后端自动测试使用假传输覆盖请求契约、成功响应和配置失败。
- [x] 前端流程测试覆盖导航、上传、必填校验、基础生成、结果预览和下载。
