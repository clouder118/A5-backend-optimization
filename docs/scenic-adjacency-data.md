# 灵山胜境相邻步行时间维护说明

## 数据文件

`knowledge/routes/ling-shan-adjacency-v1.json`

相邻时间由人工维护，不从鸟瞰图直线距离计算。当前 `v1` 使用升级方案中的
示例时间，用于比赛演示和计算链路验证，状态为 `provisional`。

## 人工复核方式

1. 在景区现场按正常游客步速记录起点和终点。
2. 每条路段至少测量两次，使用较保守的整数分钟。
3. 记录台阶、坡度、室内通道、绕行和无障碍情况。
4. 修改 JSON 中的 `walk_minutes`、`accessible` 和 `note`。
5. 将 `status` 改为 `verified`，并升级 `data_version`。
6. 重启后端后调用 `/api/routes/recommend`，核对每段和总时长。

## 缺失数据行为

- 有连通路径：累计多个人工维护路段。
- 没有连通路径：`transition_minutes` 返回 `null`。
- 路线响应的 `time_data_complete` 返回 `false`。
- 前端显示“上一站至此：时间待补充”。
- 不使用图片坐标或直线距离生成替代时间。
