## What to build

把单次结果页升级为会话式图片创作工作台。页面没有记录时保持居中的创作区与模板；首次生成后切换为上方内部滚动的创作历史和下方创作区。每次生成先在历史底部插入 1:1 Lightfall 等待项，成功后由图片原位替换，失败后移除等待项并保留所有有效输入和旧记录。

历史只存在于当前页面会话中，只记录成功图片，不记录润色和失败请求。每条记录保存生成时的提示词、参考图、清晰度、比例、数量和结果图。游客可以悬停参考图入口查看原图，重新编辑记录参数，或直接重新生成并把新结果追加到底部。

生成期间锁定会造成并发或状态冲突的操作。刷新或重新进入路由后历史清空，不建设数据库、作品库或浏览器长期存储。

## Acceptance criteria

- [x] 没有记录时页面保持居中创作区与四张模板的初始布局。
- [x] 首次生成开始后切换到上方历史区、下方创作区的历史布局。
- [x] 历史区具有固定可用高度并在自身内部滚动，不让页面随记录无限增长。
- [x] 新等待项和成功结果追加到历史底部，并自动滚动到最新位置。
- [x] 等待项始终为 1:1，并在内部铺满 Lightfall。
- [x] Lightfall 使用 PRD 确认的颜色、速度、光带、密度、辉光、缩放和光标参数。
- [x] 图片生成期间锁定上传、润色、模板、参数、生成和历史重新生成操作。
- [x] 同一页面不能并发提交多个图片生成请求。
- [x] 成功后结果图片原位替换等待动画。
- [x] 失败时等待项被移除，创作区显示可重试错误，输入、参数和旧历史全部保留。
- [x] 失败和润色不会产生历史记录。
- [x] 历史只保留在当前 React 页面会话中，刷新或重新进入后清空。
- [x] 历史记录显示提示词、参考图入口、清晰度、比例和一张数量信息。
- [x] 历史不显示模型名、版本号、API、价格或供应商品牌。
- [x] 悬停“参考图”时显示小型参考图预览。
- [x] “重新编辑”把记录快照载入创作区但不自动生成。
- [x] “重新生成”不弹确认，直接使用记录快照发起请求，成功后追加新记录。
- [x] 历史模式下模板默认收起，点击后从创作区上方向上展开。
- [x] 非正方形结果在 1:1 框中完整适配，剩余区域使用协调的浅色留白。
- [x] 前端测试覆盖初始/历史切换、等待项、滚动、成功、失败、刷新清空、重新编辑和重新生成。
