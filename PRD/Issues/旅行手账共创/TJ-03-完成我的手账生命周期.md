# TJ-03 完成“我的手账”生命周期

- 类型：AFK
- 状态：`completed`
- 用户故事：45–50、59–62

## Parent

[旅行手账共创 PRD](../../旅行手账共创-PRD.md)

## What to build

把基础草稿扩展为每位游客可长期管理的多篇手账集合。“我的手账”展示草稿和已发布状态，支持分页或增量加载、继续编辑、自动保存、复制为新草稿和删除。自动保存必须提供保存中、成功与失败反馈，刷新或重新登录后可以恢复。

已发布手账作为不可直接编辑的快照。游客继续创作时需要复制为新草稿。生命周期操作必须严格验证游客归属，并为后续社区发布和删除联动提供稳定状态转换。

## Acceptance criteria

- [x] 每位游客可以保存多篇手账，并在“我的手账”中分页或增量查看。
- [x] 列表明确区分草稿和已发布状态，并显示标题、封面或摘要、更新时间。
- [x] 草稿支持继续编辑，刷新和重新登录后内容保持一致。
- [x] 编辑采用防抖或等价自动保存，并显示保存中、成功和失败状态。
- [x] 保存失败不清空当前编辑内容，并提供重试路径。
- [x] 已发布手账不能直接编辑，可以复制为拥有独立标识的新草稿。
- [x] 删除草稿前显示确认，并清理不再被有效记录引用的素材。
- [x] 不同游客之间无法读取、编辑、复制、导出或删除对方手账。
- [x] 重复保存、复制和删除请求不会产生重复记录或半完成状态。
- [x] 后端测试覆盖多草稿、分页、归属隔离、自动保存、复制、删除和状态校验。
- [x] 前端流程测试覆盖列表、继续编辑、刷新恢复、保存状态、复制和删除确认。
