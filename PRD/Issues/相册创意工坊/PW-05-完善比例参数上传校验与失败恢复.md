## What to build

把基础生成链路完善为可稳定演示的参数与失败恢复能力。游客可以选择智能、1:1、3:4、4:3、16:9、9:16、2:3、3:2 或 21:9，并在 1K、2K 间切换；输出数量固定为一张。

后端集中把产品参数映射为 Seedream 接受的尺寸和单图控制，不让供应商参数散落在前端。上传在前后端执行格式、MIME、实际解码、大小和单图校验。更换当前参考图必须确认，确认后保留提示词和参数，且不影响既有会话历史。

模型超时、网络失败、限流、审核拒绝、缺少输出或非法响应都归一为可理解错误。系统不自动重试、不切换其他图片模型，也不暴露 Key、Authorization、供应商原始响应或堆栈。

## Acceptance criteria

- [x] 页面提供智能、1:1、3:4、4:3、16:9、9:16、2:3、3:2、21:9 九个比例选项。
- [x] 页面提供 1K 和 2K，默认智能比例、1K。
- [x] 生成数量固定为一张，只展示信息，不允许改变。
- [x] 智能比例结合上传图宽高比选择供应商支持的适配尺寸。
- [x] 八种固定比例在 1K、2K 下均由后端映射为有效模型参数。
- [x] 前端不直接拼装供应商模型名、图片尺寸或单图控制字段。
- [x] 上传只允许 JPEG、PNG、WebP，并验证扩展名、MIME 和实际解码结果。
- [x] 项目历史景区素材若扩展名误标但实际内容仍为 JPEG、PNG 或 WebP，前端按真实格式归一化上传元数据，不重编码原图且不放宽后端校验。
- [x] 单张超过 10 MB、多文件、损坏图片或伪造格式均被拒绝并显示明确错误。
- [x] 选择新参考图时显示替换确认；取消后保留原图。
- [x] 确认替换后保留当前提示词和参数，不删除成功历史。
- [x] 生成期间相关控件保持锁定，完成或失败后恢复。
- [x] 超时或网络失败不会自动重新发起可能产生费用的请求。
- [x] 供应商审核拒绝时提示游客修改内容后重试，不返回审核内部细节。
- [x] 缺图、非法响应、限流、配置错误和供应商错误统一为稳定的 API 错误。
- [x] 任意错误都不得包含 Key、Authorization、供应商完整响应或后端堆栈。
- [x] 模型失败不降级到其他图片模型，也不生成本地模拟图片。
- [x] 后端测试覆盖全部参数映射、上传边界、错误类型和敏感信息脱敏。
- [x] 前端测试覆盖参数选择、替换确认、锁定、无自动重试和失败保留。
