## Problem Statement / 问题陈述

当前游客端已经支持景区浏览、数字人导览、评论社区和旅行手账，但游客拍摄的旅行照片仍只能以原始形态保存或发布。游客如果想把照片改成动漫、Q 版、时尚杂志或不同季节等创意作品，需要离开产品寻找其他图像工具，自己理解复杂提示词，并承担操作路径割裂、提示词表达不清和生成参数难以选择的问题。

本功能需要让游客在游客端上传一张任意内容的常见图片，用自然语言描述创意想法，并通过 `doubao-seedream-5-0-pro-260628` 完成单参考图创作。游客还可以调用 `mimo-v2.5-pro` 润色和适度扩写输入，使其更适合作为图片编辑提示词，但润色结果必须保持可编辑，不能自动开始生成。

页面同时需要提供四种基于项目景区照片制作的静态模板，让游客快速理解创作能力。图片生成等待过程使用 Lightfall 动效；生成成功后以可滚动的会话内创作历史展示结果，并支持重新编辑、重新生成、大图预览和下载。所有交互必须延续游客端现有温暖、清晰的视觉语言和多边形按钮样式，避免文字与背景撞色。

本期不建设作品库、数据库历史、社区发布或移动端版本。用户上传图和生成图只在当前页面会话中使用，刷新或重新进入页面后清空。

## Solution / 解决方案

在游客端导航“旅行手账共创”下方新增“相册创意工坊”，路由为 `/photo-workshop`，沿用当前游客端访问规则，不新增账号、权限、额度、积分或计费系统。

初始页面将创作区居中展示，包含：

- 单张参考图上传入口；
- 最多 2000 字的创意想法输入框；
- `mimo-v2.5-pro` 驱动的“AI 提示词润色”按钮；
- 智能比例和八种固定比例；
- `1K`、`2K` 清晰度；
- 固定“1 张”的生成数量信息；
- 符合项目既有风格的生成按钮；
- 四张静态模板卡片：二次元/动漫、Q 版二次元、时尚杂志、季节变换。

游客点击模板时，模板提示词直接覆盖当前输入框，不弹确认框，覆盖后仍可自由编辑，也不会自动生成。模板示例图在开发阶段使用四张不同的项目景区照片和指定 Seedream 模型各生成一次，生成结果作为静态资源写入项目，页面访问时不重复调用模型。

首次生成后，页面切换为“上方创作历史、下方创作区”的模式。历史区固定高度并内部滚动，最新成功结果追加到底部并自动滚动到最新位置；底部创作区继续用于下一次生成。模板默认收起，通过“模板”入口向上展开。

每次生成期间，在历史区底部插入一个始终为 `1:1` 的 Lightfall 等待卡片。成功后由生成图片原位替换；非正方形图片完整适配到正方形显示框中，不裁剪、不拉伸，剩余区域使用与页面协调的浅色背景留白。失败时移除等待卡片，在创作区显示友好错误，保留全部输入和旧的成功历史。

创作历史只记录成功的图片生成任务，不记录提示词润色和失败请求。每条记录包含生成时的提示词、参考图入口、清晰度、比例、数量和结果图，不展示模型名、版本、API 入口或价格。参考图入口悬停时显示小型预览。游客可以重新编辑、直接重新生成、点击结果打开大图预览，并从预览右上角下载原格式、原清晰度且不加水印的图片。

## Implementation Decisions / 实施决策

### 路由、导航与访问边界

- 新增游客端路由 `/photo-workshop`，导航文字为“相册创意工坊”。
- 导航入口紧接在“旅行手账共创”下方，不调整其他入口的顺序和行为。
- 沿用当前游客端访问和登录保护方式，不新建认证、授权、额度或计费能力。
- 本期只保证 PC 端布局，不增加移动端专项适配。

### 页面状态与结构

- 页面包含两种结构状态：`initial` 与 `history`。
- `initial` 状态将创作区居中展示，四张模板卡片排列在其下方。
- 首次提交生成后切换到 `history` 状态。
- `history` 状态上方为固定高度的内部滚动历史区，下方为创作区。
- 最新等待项或成功结果追加到历史底部，并自动滚动到最新位置。
- 历史模式下模板默认收起；“模板”入口把模板面板从创作区上方向上展开。
- 模板面板在再次点击入口或选中模板后收起。
- 页面不复制参考产品的模型标题、版本、API、价格、免责声明或其他开发平台元素。

### 输入与上传

- 生成必须提供一张参考图和非空创意提示词。
- 参考图仅允许 JPEG、PNG、WebP，单张最大 10 MB。
- 前后端都必须验证文件扩展名、MIME 和实际图片解码结果。
- 对项目历史景区素材中扩展名误标、但实际内容仍为 JPEG、PNG 或 WebP 的文件，前端按真实格式归一化上传文件名和 MIME；不重编码原图，后端继续执行严格一致性校验。
- 选择新参考图时弹出替换确认；确认后替换当前参考图，保留当前提示词和生成参数。
- 更换当前参考图不删除已经成功的会话历史。
- 创意提示词最大 2000 个字符，显示实时字符数。
- 达到字符上限后阻止继续输入，不静默截断已有内容。

### AI 提示词润色

- 润色使用后端专用接口调用 `mimo-v2.5-pro`，不改变数字人聊天当前使用的模型配置。
- 润色接口只接收文字，不读取参考图。
- 未上传图片时仍可润色；空提示词不能润色。
- 润色期间仅润色按钮显示加载并禁止重复点击，不启用 Lightfall。
- 润色成功后覆盖当前输入框，保持可编辑，不自动生成。
- 润色失败时保留原文，返回脱敏后的用户错误。
- 润色系统规则遵循：
  - 使用自然、清晰、具体的表达；
  - 优先组织为主体、动作、环境；
  - 按需补充风格、色彩、光影、构图；
  - 明确应用场景和用途；
  - 使用精准风格词或说明参考图作用；
  - 需要渲染的文字放入双引号；
  - 明确修改对象、具体操作和必须保持不变的部分；
  - 允许适度扩写，但不得改变游客核心意图或擅自加入无关主体。

### 模板卡片

- 固定四张模板卡片：二次元/动漫、Q 版二次元、时尚杂志、季节变换。
- 四张卡片使用四张不同的现有项目景区照片。
- 用户提供 Seedream API Key 后，在开发阶段使用 `doubao-seedream-5-0-pro-260628` 各生成一次模板图。
- 模板生成图作为静态资源保存到项目；页面访问不调用模型重新生成模板。
- 每张模板包含固定提示词；悬停展示提示词摘要和体验入口。
- 点击模板时直接覆盖当前提示词，不弹确认、不自动生成，覆盖后仍可编辑。
- 时尚杂志模板不新增独立标题输入；提示词以双引号标记可替换的景点名称或杂志文字。

### 图片生成参数

- 图片生成使用 `doubao-seedream-5-0-pro-260628`，单次一张参考图、单次输出一张图片。
- 默认参数为智能比例、1K、1 张。
- 比例选项为智能、1:1、3:4、4:3、16:9、9:16、2:3、3:2、21:9。
- 智能比例根据上传图原始宽高比和模型能力选择适配尺寸。
- 固定比例由后端统一映射为模型接受的 1K/2K 尺寸，前端不拼装供应商参数。
- 清晰度仅提供 1K 和 2K。
- 生成数量固定为一张，只展示状态，不提供数量选择。
- 供应商地址、模型名、超时和 Key 通过后端集中配置，不硬编码在前端。
- Seedream 配置与现有 MiMo、Kimi 配置隔离，避免改变数字人对话和旅行手账行为。
- Key 只存在于被 Git 忽略的后端 `.env` 或部署环境变量；示例配置只记录变量名。

### 生成状态与 Lightfall

- 生成开始后立即在历史底部插入一个 1:1 等待卡片。
- 等待卡片内部铺满 Lightfall，不改变历史卡片外部尺寸。
- Lightfall 使用以下已确认参数：
  - Color 1：`#a6c8ff`
  - Color 2：`#5227ff`
  - Color 3：`#ff9ffc`
  - Background：`#0a29ff`
  - Cursor Light：开启
  - Speed：`0.5`
  - Streak Count：`2`
  - Streak Width：`1`
  - Streak Length：`1`
  - Density：`0.6`
  - Twinkle：`1`
  - Glow：`1`
  - Background Glow：`0.5`
  - Zoom：`3`
  - Cursor Strength：`0.5`
  - Cursor Radius：`1`
- 图片生成期间锁定上传、润色、模板选择、参数切换、生成和历史重新生成操作。
- 同一页面不允许并发图片生成请求。
- 服务超时或网络失败时不自动重试；由游客主动点击重试或重新生成。
- 成功后生成图片原位替换动效。
- 失败后移除等待卡片，在创作区显示错误，保留当前输入、参数和已有历史。

### 会话内创作历史

- 历史仅保存在当前 React 页面会话状态中，不写入数据库、作品库或浏览器长期存储。
- 刷新页面、关闭标签或重新进入路由后历史清空。
- 历史只记录成功生成任务，不记录润色和失败请求。
- 每条记录保留生成时的提示词、参考图会话副本、清晰度、比例、数量、结果图和时间。
- 生成成功后结果追加到历史底部，旧记录保持不变。
- 历史记录不展示供应商模型名、版本号、API 入口、价格或计费说明。
- “参考图”入口显示缩略图，鼠标悬停时弹出小型参考图预览。
- “重新编辑”把记录的参考图、提示词、比例和清晰度载入底部创作区，不发起生成。
- “重新生成”使用记录快照直接发起请求，不弹确认；成功结果作为新记录追加到底部。

### 结果展示、预览与下载

- 页面内等待框与结果框始终保持 1:1。
- 结果图使用完整适配展示，不裁剪、不拉伸。
- 非正方形图片的剩余区域使用与页面背景协调的浅色留白。
- 点击结果图打开大图预览。
- 大图预览只提供关闭/返回和右上角下载，不实现点赞、点踩、编辑、收藏、分享或删除。
- 下载保留模型返回的文件格式和清晰度，不额外压缩、不添加项目水印。
- 下载文件名为“灵诗音-相册创意-日期时间”，并清理操作系统不允许的字符。

### 后端接口边界

- 前端页面不直接调用 MiMo 或 Seedream；所有远程请求通过现有统一 API 层进入后端。
- 后端提供独立的提示词润色与图片生成能力，负责供应商请求、超时、响应解析和错误归一化。
- 图片生成请求使用受控的服务端文件转换或 Base64/供应商支持格式，不要求用户图片具备公网 URL。
- 后端向前端返回可预览和下载的图片结果与必要元数据，但不建立长期资产记录。
- 如供应商返回短期 URL，后端必须在当前请求链路内转换为不依赖供应商 URL 长期有效性的结果。
- 供应商拒绝、审核失败、限流、超时、返回缺图或非法数据时，统一转换为不含 Key、上游响应体和堆栈的错误。

### 内容安全

- 上传图和提示词遵循模型服务商的内容安全与审核规则。
- 本期不增加自定义审核后台、审核队列或申诉流程。
- 输入、参考图或输出被拒绝时，提示游客修改内容后重试。
- 不向前端返回供应商内部审核策略、原始错误、请求凭证或敏感技术信息。

### 视觉语言

- 使用现有游客端暖色、浅色背景、边框、阴影、字体层级和间距。
- 可操作按钮沿用项目现有多边形切角按钮形状和配色逻辑。
- 所有文字与背景必须有清晰对比；输入值、占位文字、禁用态、弹窗文字和标签均需检查可读性。
- 不照搬参考产品的紫色平台 UI，只复用已确认的页面结构和交互关系。
- 不引入新的通用 UI 框架。

### 主要深模块

1. 图片生成服务：集中处理上传校验、比例尺寸映射、Seedream 请求、单图响应和错误脱敏。
2. 提示词润色服务：封装 `mimo-v2.5-pro` 调用、润色规则、2000 字边界和失败保留。
3. 会话创作状态：以明确状态管理初始/历史布局、等待项、成功记录、重新编辑、重新生成和并发锁。
4. PC 端工坊界面：组合路由、创作器、参数面板、模板面板、历史滚动、Lightfall、预览和下载。
5. 静态模板资产：选择项目景区原图，完成四种 Seedream 示例生成，并保存模板图与固定提示词。

## Testing Decisions / 测试决策

### 测试原则

- 自动化测试只验证外部可观察行为，不绑定私有函数、CSS 类名或内部组件拆分。
- 自动化测试不得读取真实 API Key，也不得调用真实 MiMo 或 Seedream。
- 后端供应商调用使用可控替身，验证请求契约、响应解析和错误恢复。
- 文件测试使用内存数据或临时目录，不污染项目景区素材和本地运行数据。
- 现有数字人聊天、旅行手账、评论社区和游客导航测试继续通过。
- Lightfall 只验证加载状态存在与生命周期，不做易碎的逐像素动画截图断言。

### 后端自动测试

- JPEG、PNG、WebP 成功输入，以及错误格式、伪造 MIME、无法解码、超过 10 MB 和多图拒绝。
- 空提示词、超过 2000 字和缺少参考图的生成校验。
- 未上传图片时仍可调用非空文字润色。
- 润色请求使用 `mimo-v2.5-pro`、已确认润色规则和专用模型配置。
- 润色成功、超长响应、空响应、超时、拒绝和错误脱敏。
- 智能比例与八种固定比例在 1K、2K 下映射到合法供应商参数。
- Seedream 请求使用指定模型、单张参考图、单图输出和无水印配置。
- Seedream URL/Base64 或实际官方返回形态的成功解析。
- 供应商返回缺图、部分错误、非法数据、超时、限流和审核拒绝时的统一错误。
- 任何失败都不泄露 Key、Authorization、上游完整响应或堆栈。

### 前端自动测试

- “相册创意工坊”位于“旅行手账共创”下方，路由和现有访问保护正确。
- 初始状态为居中创作区与四张模板。
- 上传格式、大小、单图约束、替换确认和生成必填校验。
- 字数计数、2000 字上限、润色加载、成功覆盖、失败保留和不自动生成。
- 模板悬停说明、直接覆盖已有输入、不自动生成和历史模式向上展开。
- 默认智能比例、1K、1 张，以及全部比例和清晰度选择。
- 首次生成切换历史模式、插入 1:1 等待项、锁定并发和失败恢复。
- 成功结果替换等待项、追加到底部、历史内部滚动和自动定位最新结果。
- 非正方形结果保持完整适配，不使用裁剪展示。
- 历史不记录润色和失败请求，不显示模型、API 或价格信息。
- 参考图悬停预览、重新编辑回填、直接重新生成和新结果追加。
- 点击结果进入大图预览，预览只有关闭/返回和下载。
- 下载文件名规则、浏览器收到文件，以及刷新后会话历史清空。
