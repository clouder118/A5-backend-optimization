## What to build

交付四类可直接体验的创意模板交互：二次元/动漫、Q 版二次元、时尚杂志、季节变换。每张卡片使用不同的项目景区素材，并关联一段遵循 Seedream 提示词规则的固定文本。

初始状态下四张模板以一行四列展示。游客悬停卡片时看到提示词说明，点击后模板提示词直接覆盖当前输入框，不弹确认、不自动生成，且仍可继续编辑。时尚杂志模板通过提示词中的双引号表达可替换景点名称，不增加额外标题表单。

本切片先使用项目已有景区图完成模板交互和正式静态资源插槽；通过真实 Seedream 生成的四张最终模板图由 PW-06 在取得 Key 后替换。

## Acceptance criteria

- [x] 初始页面展示二次元/动漫、Q 版二次元、时尚杂志、季节变换四张卡片。
- [x] PC 端四张模板按一行四列排布，间距、边框、阴影和文字对比符合现有页面。
- [x] 四张卡片分别使用不同的现有项目景区素材。
- [x] 每张模板关联稳定的名称、提示词、图片和悬停说明。
- [x] 悬停模板时显示提示词用途和体验入口，离开后恢复简洁卡面。
- [x] 点击模板会直接覆盖空输入框或已有内容，不弹确认框。
- [x] 模板填入后提示词仍可编辑，且不会自动调用润色或图片生成。
- [x] 时尚杂志模板不新增独立标题输入，并在提示词中用双引号表达可替换景点名称。
- [x] 初始状态直接展示模板；创作区同时提供可用于历史模式的“模板”开关入口。
- [x] 模板面板支持从创作区上方向上展开，并可通过再次点击或选择模板收起。
- [x] 模板数据与页面组合逻辑分离，PW-06 可以只替换最终静态图而不重写交互。
- [x] 前端测试覆盖四张卡片、悬停说明、已有文字直接覆盖、不自动生成和展开/收起。
