# TJ-02 接入多图素材与 Kimi K3 图文共创

## What to build

把纯文字共创扩展为完整多模态图文共创。游客可以通过点击、多选或拖拽上传 0–9 张 JPEG、PNG 或 WebP 旅行照片，查看缩略图，删除并拖动排序。服务端验证真实图片内容，移除 EXIF，生成高质量展示副本和更小的模型识别副本，不长期保存原始文件。

生成时将当前全部模型图片副本、游客描述、图片顺序和目标字数放入一次 Kimi K3 多模态请求。结构化结果必须把每个图片标识准确映射到一个小标题和讲述段落，最终编辑器按照游客顺序显示图文。纯图片、纯文字和图文混合三种输入都必须可用。

## Acceptance criteria

- [x] 支持点击选择、一次多选和拖拽上传。
- [x] 每篇允许 0–9 张图片，单张最大 10 MB，格式仅限 JPEG、PNG、WebP。
- [x] 图片与文字至少提供一项；两者都为空时禁止生成。
- [x] 上传区显示缩略图、顺序编号、删除操作和拖动排序。
- [x] 服务端验证 MIME、实际解码结果、大小、数量和资源归属，文件路径不使用游客原始文件名。
- [x] Pillow 生成最长边不超过 2560px 的展示副本并移除 EXIF。
- [x] 另生成受控尺寸的模型副本，原始文件处理后不长期保留。
- [x] 一次 Kimi 请求包含当前全部图片、描述、目标字数和稳定图片标识，Body 保持在 100 MB 内。
- [x] 每张图片在结构化结果中出现且只出现一次，缺失、重复或未知图片标识会触发可重试错误。
- [x] 每个图片块包含图片、小标题和对应讲述，并按照游客排序展示。
- [x] 图片与讲述作为整体排序或删除。
- [x] 生成后新增图片时创建空的可编辑讲述，不自动调用模型。
- [x] 游客可以主动重新生成全部素材，已有内容先经过覆盖确认。
- [x] 自动化测试覆盖纯图片、单图、多图、九图、格式错误、超限、EXIF 移除和 Kimi 多图请求结构。
- [x] 前端流程测试覆盖上传、多选、拖拽、排序、删除、九图上限和图文对应编辑。
