# TJ-01 建立纯文字手账共创闭环

- 类型：AFK
- 状态：`completed`
- 用户故事：1–4、9–11、19–25、30–40、68–72

## Parent

[旅行手账共创 PRD](../../旅行手账共创-PRD.md)

## What to build

交付一条可独立演示的纯文字旅行手账共创链路。已登录游客可以从侧边栏进入“旅行手账共创”，填写旅途描述，选择预设或自定义目标字数，调用独立配置的 Kimi K3 生成固定结构文章。结果包含标题、开场、3–5 个正文段落和结尾，回填到可编辑界面并实时预览，同时保存为当前游客的草稿。

Kimi 请求使用 `kimi-k3`、低推理强度和严格结构化输出。模型未配置、超时或返回非法结构时，游客输入和已有草稿必须保留，且不得切换 MiMo 或生成模拟文章。自动化测试必须替换真实模型调用，不能消费真实密钥。

## Acceptance criteria

- [x] 已登录游客可以通过“评论社区”下方的“旅行手账共创”入口访问受保护页面。
- [x] 页面包含“共创手账”和“我的手账”两个标签入口，并提供符合现有游客端风格的 PC 布局。
- [x] 旅途描述最多 2000 个字符；本切片未上传图片时，空描述不能生成。
- [x] 提供 300、600、1000、1500 字预设档位，默认 600 字。
- [x] 自定义字数只接受 200–3000 的整数。
- [x] 生成请求使用独立 Kimi 配置、`kimi-k3` 和低推理强度。
- [x] Kimi 最终结果通过严格结构校验，包含标题、开场、3–5 个正文段落和结尾。
- [x] 生成结果回填后仍可编辑并显示公众号式实时预览。
- [x] 再次生成已有内容前显示覆盖确认。
- [x] 生成完成后自动保存草稿，但不自动发布、跳转或导出。
- [x] 模型失败时显示可重试错误，并保留描述、字数与当前文章。
- [x] API Key 只从后端环境变量读取，不出现在客户端、错误信息、日志、文档或提交中。
- [x] 后端测试覆盖身份隔离、输入校验、Kimi 请求契约、合法与非法结构及失败恢复。
- [x] 前端流程测试覆盖纯文字生成、编辑、预览、覆盖确认和刷新恢复。
