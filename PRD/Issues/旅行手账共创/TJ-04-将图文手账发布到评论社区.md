# TJ-04 将图文手账发布到评论社区

- 类型：AFK
- 状态：`completed`
- 用户故事：51–62、70

## Parent

[旅行手账共创 PRD](../../旅行手账共创-PRD.md)

## What to build

把完整旅行手账作为新的图文帖子类型接入评论社区。发布前明确提示标题、正文和图片将公开；确认后在一个一致性操作中创建社区帖子并把手账标记为已发布。发布成功跳转到评论社区，定位并高亮刚发布的帖子。

社区列表中的旅行手账展示封面、标题和摘要，点击后在当前页面打开大尺寸纵向图文阅读弹窗。现有普通文字评论继续执行原有 500 字、关联景点、点赞、删除和管理逻辑。旅行手账进入现有社区治理流程，并实现手账与帖子删除状态的双向联动。

## Acceptance criteria

- [x] 点击发布先显示公开确认，取消后不改变草稿。
- [x] 确认发布会一致地创建社区帖子并更新手账状态，不出现单边成功。
- [x] 发布失败时留在编辑页，保留草稿和全部素材。
- [x] 发布成功后跳转到 `/community`，定位并高亮新旅行手账。
- [x] 社区旅行手账卡片展示封面、标题、摘要、作者、时间和现有公共互动信息。
- [x] 点击卡片在当前社区页面打开完整图文阅读弹窗，不新增详情路由。
- [x] 普通文字评论继续保持原有 500 字限制、接口兼容和展示样式。
- [x] 已发布手账为不可直接覆盖的快照，复制产生的新草稿不会改变社区内容。
- [x] 删除已发布手账会同步软删除对应社区帖子，并经过明确确认。
- [x] 游客在社区删除旅行手账后，手账内容保留并转回未发布草稿。
- [x] 旅行手账可以进入现有管理员隐藏和恢复流程。
- [x] 后端测试覆盖发布事务、重复发布、普通评论兼容、权限和双向删除联动。
- [x] 前端流程测试覆盖发布确认、失败保留、成功跳转高亮、卡片和完整阅读弹窗。
